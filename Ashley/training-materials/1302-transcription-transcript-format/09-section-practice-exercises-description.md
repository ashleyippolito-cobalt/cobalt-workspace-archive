# Section: Practice Exercises - Description

<!-- https://classes.saltsoftware.com/course/section.php?id=61 -->

Section outline

There are two short samples for you to use as practice. The audio files and SALT transcript files with header information are provided for you. For each practice sample, you should 1) download the audio file, 2) download the SALT transcript file with header information, 3) transcribe the audio sample using the SALT editor, headphones, and a digital playback system, and 4) compare your transcript with the "master" transcript.

When transcribing the samples you will type the language of both speakers, inserting speaker identifiers and ending punctuation. You will also insert a final timing marker to indicate elapsed time.
