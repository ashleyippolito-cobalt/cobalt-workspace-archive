Section outline

Analyze Dan's first sample (Dan 11;2 coded) in SALT and answer the Self Check questions.

There are several ways to analyze codes within a SALT transcript. From the Analyze menu, you can use the Code Summary, Utterance Code Tables, or Standard Utterance Lists. For this exercise, we will use the Utterance Code Tables. Note that all the custom codes were entered as utterance codes; none of them were word codes.

Start up your copy of the SALT software.
Open the transcript file Dan 11;2 coded.slt that you just downloaded.
Select Analyze menu --> Utterance Code Tables.
The dialogue box for the utterance code tables has a number of options.
Select the table expanded by utterances.
Include codes from either speaker - Dan and the examiner. The reason for including the examiner is because the examiner's questions were coded as [NR] when Dan failed to respond.
Include total utterances, not just those in the current analysis set.
There are several utterances coded as [EU], indicating an utterance-level error. Change the setting so that error codes are not included.
List each utterance in the context of 2 preceding entries. You are looking at responses to questions, so being able to see what kind of questions were asked would be useful information for your analysis.
Number the entries.
Generate the Utterance Code Table. You may want to print a copy of the table so you can use the results to answer the check questions that follow.
Select "Self Check" and answer the questions.
