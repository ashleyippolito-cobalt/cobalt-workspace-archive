Case Study/Demo Video

This section of the course focuses on how to apply specialized or custom coding to a language sample. Custom coding allows for flexible analysis. By inserting specialized codes using brackets, e.g. [code], to a language sample, one can account for any language feature of interest. Examples of specialized coding include: dialectal features, fluency, response to questions, pronouns, prepositions, and so on. Specialized coding schemes can also be used over multiple language samples to track progress in therapy.

Practice Exercises

In this section, you will analyze coded samples on your own.

Dan's language sample required custom coding to capture his unique oral language patterns and to track if he improved his therapy goal of increasing appropriate responses to questions. Dan's sample was coded using the following coding schemes:

Language
[L:REP]: Repetition - utterances where Dan repeated a word once or multiple times
[L:ECH]: Echolalia - utterances where Dan repeated language from the clinician
Discourse
[D:IR]: Inappropriate response to question
[D:AR]: Appropriate response to question
[D:NR]: No response to question
[D:TOP]: Off topic, deviating from the topic

Practice - Part 1

Analyze Dan's first sample (Dan 11;2 coded) in SALT and answer the Self Check questions.

There are several ways to analyze codes within a SALT transcript. From the Analyze menu, you can use the Code Summary, Utterance Code Tables, or Standard Utterance Lists. For this exercise, we will use the Utterance Code Tables. Note that all the custom codes were entered as utterance codes; none of them were word codes.

Start up your copy of the SALT software.
Open the transcript file Dan 11;2 coded.slt that you just downloaded.
Select Analyze menu --> Utterance Code Tables.
The dialogue box for the utterance code tables has a number of options.
Select the table expanded by utterances.
Include codes from either speaker - Dan and the examiner. The reason for including the examiner is because the examiner's questions were coded as [NR] when Dan failed to respond.
Include total utterances, not just those in the current analysis set.
There are several utterances coded as [EU], indicating an utterance-level error. Change the setting so that error codes are not included.
List each utterance in the context of 2 preceding entries. You are looking at responses to questions, so being able to see what kind of questions were asked would be useful information for your analysis.
Number the entries.
Generate the Utterance Code Table. You may want to print a copy of the table so you can use the results to answer the check questions that follow.
Select "Self Check" and answer the questions.

Link Dan's two coded samples to look at change over time.

Link Dan's two coded samples together and generate the Utterance Code Table.

Summary

Dan continues to demonstrate profound expressive language deficits characterized by echolalia and repeated words. He did, however, improve his therapy goal of increasing appropriate responses to questions. Dan increased the number of appropriate responses from time one to time two, and decreased the number of inappropriate and off-topic responses.

Keep in mind that this is just one illustration of how to apply very specific codes to a language sample to document various aspects of language. You may have other therapy goals which could be documented through a specific coding scheme of your own. Applying specialized coding schemes allows you to quantify and track specific features of the speakers' language. Use the utilities built into SALT to simplify coding. Create a list of your codes and insert them consistently within and across your language samples. Then select from a variety of code reports to count your codes and pull up the words and utterances containing them.
