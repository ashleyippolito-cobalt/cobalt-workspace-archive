# Section: Practice Exercises - Description

<!-- https://classes.saltsoftware.com/course/section.php?id=77 -->

Section outline

Continuing with the Andy and Kelina samples from the previous transcription courses, practice transcribing bound morphemes, mazes, part words, and unfilled pauses. The audio files and SALT transcript files are provided for you. For each sample, you should 1) download the audio file, 2) download the SALT transcript file, 3) code the transcript for bound morphemes, mazes, part words, and unfilled pauses using the SALT editor, headphones, and a digital playback system, and 4) compare your transcript with the "master" transcript.

When coding the samples, mark bound morphemes, mazes, part words, and pauses.
