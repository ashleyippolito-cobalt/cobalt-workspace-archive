# Section: Practice Exercises - Description

<!-- https://classes.saltsoftware.com/course/section.php?id=98 -->

Section outline

Wrap up transcription of the Andy and Kelina samples from the previous transcription courses. The audio files and SALT transcript files are provided for you. For each sample, you should 1) download the audio file, 2) download the SALT transcript file, 3) code the transcript for the word-level conventions using the SALT editor, headphones, and a digital playback system, and 4) compare your transcript with the "master" transcript.

When coding the samples, mark examiner feedback, omissions, and errors.
