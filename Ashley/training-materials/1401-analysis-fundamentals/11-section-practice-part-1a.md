Section outline
Use SALT to generate the database Standard Measures Report.


SALT 20 and SALT 18

Start up your copy of the SALT software.
Open the transcript file Max Expo.slt. This is one of the sample transcripts found in the Lesson Samples subfolder. If you cannot locate this transcript, you may download it below.
Select Database menu --> Select Database Samples and Settings

Notice the information across the bottom of the dialog box. Max is 11 years old and is in the 5th grade. His expository sample contains 252 total words, 32 complete and intelligible utterances, and has an elapsed time of just over 4 minutes.

STEP 1: Use the default database- Expository
STEP 2: Use the default age match +/- 6 months. Then click the Find Matched Samples button and notice that 88 samples matched.


SALT 20

STEP 3: Some language measures, such as Number Different Words, Utterances with Mazes, and Omitted Words are affected by the length of the sample because longer samples provide more opportunity. When equating samples in SALT, you have the option of comparing samples based on the same number of total words, same number of utterances, or same amount of elapsed time. For this exercise, equate samples using the Same number of total words. Then click the Find Equated Samples button. When prompted to select the best comparison set, select the option with 83 samples - 252 words. Click OK.
Select OK to close the selection dialog box.
Select Database menu --> Standard Measures Report. 
You have the option of generating this report using the entire transcript (88 samples) or the subset of samples equated by length (83 samples). When prompted, select the setting, Entire transcript (the recommended setting) and click OK. 


SALT 18

STEP 3: Some language measures, such as Number Different Words, Utterances with Mazes, and Omitted Words are affected by the length of the sample because longer samples provide more opportunity. When equating samples in SALT, you have the option of comparing samples based on the same number of total words, same number of utterances, or same amount of elapsed time. For this exercise, however, select Entire transcript (regardless of length). Note that all the language measures will be based on the entire transcript rather than being equated by the same length. Click the Find Equated Samples button. The same 88 samples are selected.
Select OK to close the selection dialog box.
Select Database menu --> Standard Measures Report. 


SALT 20 and SALT 18

After a slight delay the Standard Measures Report is displayed. You may want to print this report so you have it to refer to when answering the Self Check questions.

Select "Self Check" (below) and answer the questions.
