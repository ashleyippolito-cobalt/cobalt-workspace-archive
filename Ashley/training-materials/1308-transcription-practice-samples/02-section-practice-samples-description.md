# Section: Practice Samples - Description

<!-- https://classes.saltsoftware.com/course/section.php?id=102 -->

Section outline

There are six short audio samples for you to use as practice. These samples are in order from easiest to most difficult. You should 1) download each audio file, 2) transcribe it using the SALT editor, headphones, and a digital playback system to control the audio, and 3) compare your transcript with the "master" transcript.

You may find it helpful to print out the Transcription Conventions Summary if you have not already done so in in a previous course.
