Transcription Requirements

SALT software and an audio/video playback system are required to transcribe a language sample. A hands-free foot pedal option to manipulate the audio/video file reduces transcription time and increases the accuracy of the transcript. Starting a Transcript

When you open the SALT program, you are presented with a dialogue box with the option to create a new transcript or open an existing transcript. 




If you are creating a new transcript you are presented with the "New Transcript-Header Information" dialogue box where you enter all pertinent information about your transcript such as the target speaker, other speakers, gender, date of birth, date of sample, sampling context and subgroup/story, target language, and initial clock time. There's also a section to add additional header information unique to your sample. Once you have filled in all required information a new transcript with a header is created.

After the transcript has been created with all the necessary header information, there are a few other critical formatting conventions for a SALT transcript. Beginning and ending clock times are marked with a hyphen (-). The speaker label line in the header identifies all speakers, therefore all speaker utterances need to start with the same letter as the speakers identified in the header, e.g., C for "Child" and E for "Examiner".  Between utterance pauses are marked with semicolon (;) if there is not a change in the speaker or a  colon (:) if there is a change in speakers. All speaker utterances end with standard punctuation such as a period, question mark, or exclamation point. Other ending punctuation includes tilde (~) for clinician prompts, carrot (^) for interrupted utterances, and a greater than sign (>) for abandoned utterances.
