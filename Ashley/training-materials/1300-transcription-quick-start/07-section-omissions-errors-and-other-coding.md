# Section: Omissions, Errors, and Other Coding

<!-- https://classes.saltsoftware.com/course/section.php?id=247 -->

Section outline

Omissions and errors should be marked within a transcript to determine the potential of a language impairment based on language skills that are still developing, absent, or used incorrectly. There are several different conventions to mark omissions and errors.

Omissions

Both omitted words and omitted bound morphemes are marked with an asterisk (*). The asterisk is placed before the omitted word or before the omitted bound morpheme.

Examples

Omitted Words	

It *is here.

I want *to eat it.

The frog was not *in the jar.


Omitted Morphemes	

The car go/*3s fast.

I am make/*ing you a muffin.

He/*'s go/ing home.

Error Codes

SALT uses standard error codes in the database comparison samples. Error codes are marked using square brackets [  ]. Error codes can be used at the word level (attached to words) or at the utterance level (not attached to words). SALT database comparison transcripts use [EW:__] for word level errors, [EW] to mark extraneous words, and [EO:__] to mark overgeneralization errors. Root forms of words can also be coded when marking overgeneralization errors. [EU] is used to mark utterance-level errors. It is used when there are three or more errors in an utterance, or if there are syntax errors that are not easily repaired using word level codes. Note that the Setup menu --> Lists --> Standard Code Lists option is used to view or edit the list of codes which SALT recognizes as error codes.

Examples

Word-Level Errors	

Him[EW:he] is look/ing everywhere for his frog.

They is[EW:are] right there.

The more[EW] better to see you with my dear.

It was hises|his[EO:his] video game.

We wented|go[EO:went] to Grandma/z house.

There were peoples|people[EO:people] there.


Utterance-Level Errors	

I never not did that [EU].

The store go/ing to Grandma/z [EU].

And you/'re allowed to the first person with bat [EU].

Custom Codes 

Non-standard codes can also be used in SALT to mark features for which there isn't a transcript convention. Clinicians may be interested in examining pronoun use, appropriateness of responses to questions, dialect use, or disfluencies. Any code can be used as long as it it entered inside square brackets [  ], for example the code [IR] may be used to code an utterance that was an "inappropriate response" to a question, e.g., off topic.
