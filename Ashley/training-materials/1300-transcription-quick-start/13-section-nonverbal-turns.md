# Section: Nonverbal Turns

<!-- https://classes.saltsoftware.com/course/section.php?id=251 -->

Section outline

Nonverbal utterances which hold communicative intent should be marked within a transcript using curly braces {  }. Examples:

C Lookit {C points to toy}.




E Do you like truck/s?

C {nods head}.
