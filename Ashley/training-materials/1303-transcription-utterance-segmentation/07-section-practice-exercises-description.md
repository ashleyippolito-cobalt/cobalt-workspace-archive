# Section: Practice Exercises - Description

<!-- https://classes.saltsoftware.com/course/section.php?id=68 -->

Section outline

Practice segmenting utterances into C-units using the same Andy and Kelina samples from the previous transcription course. The audio files and SALT transcript files are provided for you. For each practice sample, you should 1) download the audio file, 2) download the SALT transcript file, 3) segment the transcript into communication units (C-units) using the SALT editor, headphones, and a digital playback system, and 4) compare your transcript with the "master" transcript.

When segmenting the utterances, follow the grammatical rules and listen for pause and intonation cues.
