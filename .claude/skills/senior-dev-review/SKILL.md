Invoke a 15+ year software engineer for code review and architecture feedback.

```bash
/senior-dev-review
```

Use when:
- Reviewing PR changes for quality and patterns
- Evaluating architectural decisions
- Refactoring complex code sections
- Assessing test coverage and edge cases

The reviewer will audit for best practices, security, and technical debt.
